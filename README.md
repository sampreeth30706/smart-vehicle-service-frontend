# Smart Vehicle Service & Management System — Frontend (React + Tailwind CSS + Vite)

Role-based frontend portal for the **Smart Vehicle Service & Management System** supporting **Customer**, **Mechanic**, and **Administrator** consoles, 9-stage repair lifecycle tracking with approval & payment gates, 21-system AI vehicle diagnostic & cost estimator, Insurance/PUC compliance scheduling, and GST digital invoices.

## Tech Stack
- **React 18** + **Vite**
- **Tailwind CSS** + **Lucide Icons**
- Real-time REST API & SQLite / Spring Boot integration (`/api/*` proxy to port `8080`)

## Quick Start
```bash
npm install
npm run dev
```
Open **http://localhost:5173** in your browser.
